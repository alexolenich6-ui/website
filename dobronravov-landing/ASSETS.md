# Ассеты — что куда положить

> Лендинг построен **text-first** и полностью работает без фотографий
> (image-блоки рендерятся как аккуратные тёмные слоты в палитре бренда —
> `.asset-slot`). Когда появятся реальные фото и скрины отзывов из брифа (§6),
> положите их по путям ниже — слоты заменяются на `<Image>` в один шаг.
>
> **Файлы из брифа (§6) в загрузку не пришли** — пришли только 3 `.docx`.
> Поэтому ниже — карта «исходник из брифа → целевой путь».

## Отзывы (скрины) → `public/reviews/`

Согласия получены (§7). Публиковать **обезличенно**: скрыть имена, аватары,
телефоны. Оригиналы не редактировать; цитаты со словами «лечение / схема
лечения» (`1a47b7f6`) **не акцентировать**.

Скрины из брифа: `d9b890c9`, `332b322d`, `65fb1d06`, `7198b877`, `86facc8e`,
`0c4d764c`, `01324055`, `4020ec75`, `1a47b7f6` → `public/reviews/01.jpg …`.

Сетка слотов в `src/components/Reviews.tsx` (`reviewSlots`) — заменить на `<Image>`.

## OG-обложка → `public/og/cover.jpg`

1200×630, тёмная, с именем и обещанием «Вернуться к себе». После добавления
раскомментировать `openGraph.images` в `src/app/layout.tsx`.

## Оптимизация

Большие JPEG/PNG прогнать в WebP/AVIF (Next отдаёт AVIF/WebP автоматически
при использовании `next/image`). Исходники держать ≤ 2500px по длинной стороне.
